UAV Viewer — изучение устройства БПЛА (прототип)
==================================================

ЗАПУСК (Windows)
  Дважды щёлкните «Запуск.bat». Откроется браузер с программой.
  Окно с чёрным фоном не закрывайте, пока работаете: это локальный сервер.
  Установка и права администратора не нужны, интернет не нужен.
  Папку можно копировать и запускать с флешки.

ЗАПУСК (Linux, Astra Linux)
  Положите Node.js версии 22 или новее в runtime/node (или установите node в системе),
  затем запустите ./start.sh

ВХОД
  Пользователь:    user  / user
  Администратор:   admin / admin

ДАННЫЕ
  Всё хранится в папке data/ рядом с программой (база uav.db и загруженные файлы).
  Резервная копия — просто скопировать папку data/.

ПЕРЕНОС СХЕМ НА ДРУГИЕ КОМПЬЮТЕРЫ
  Администратор: левая панель → «Экспорт» — получится файл .uavpack.
  На другом компьютере: вход администратором → «Импорт» → выбрать файл.

ЕСЛИ ПОРТ 3000 ЗАНЯТ
  Откройте консоль в этой папке и выполните:  set "PORT=3001" && Запуск.bat

ОБЩИЙ СЕРВЕР (если появится)
  Эту же папку можно запустить на сервере для всех:
    set "HOST=0.0.0.0" && runtime\node.exe app\server.mjs
  Остальные открывают http://<адрес-сервера>:3000 в браузере.

# Отчёт диагностики в Telegram

В «…» → «Отладка» есть три кнопки:

- **Отправить отчёт.** Заново проверяет датчики (можно на ходу), собирает отчёт и отправляет его файлом в ваш Telegram-бот.
- **Проверить датчики.** Только проверка, результат в «Журнале OBD».
- **Поделиться.** Тот же отчёт через системное меню Android: Telegram, почта, файлы. Работает и без бота.

Кроме того, после первого подключения к ELM327 за запуск приложения отчёт уходит в бот сам.

Что в отчёте:
- каждый нужный PID: заявлен ли он ЭБУ, сырой ответ и значение;
- все текущие показания и бортовой компьютер;
- почему каждое «—» на экране пустое;
- откуда взялась погода: координаты, возраст геопозиции, ответ Open-Meteo;
- история показаний раз в минуту за последние полтора часа;
- журнал обмена с адаптером.

## Настройка бота (один раз)

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя и username. BotFather пришлёт **токен** вида `123456789:AA...`.
2. Откройте своего нового бота и нажмите **Start** (или напишите ему что угодно).
3. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`. В ответе найдите `"chat":{"id":123456789` — это **chat id**.
4. Добавьте два секрета в GitHub → Settings → Secrets and variables → Actions:
   - `CARSCAN_TG_BOT_TOKEN` — токен;
   - `CARSCAN_TG_CHAT_ID` — chat id.
5. Для сборок из Android Studio создайте в корне проекта файл `telegram.properties` (в git он не попадает):
   ```
   botToken=123456789:AA...
   chatId=123456789
   ```

Следующий релиз (тег `v…`) будет собран уже с ботом. В «Отладке» строка «Telegram-бот» покажет «Настроен».

**Безопасность.** Токен зашит в APK, а релизы на GitHub публичные. Кто-то может извлечь токен из APK и писать от имени бота в этот чат. Доступа к вашему Telegram-аккаунту токен не даёт. Если начнётся спам, отзовите токен в @BotFather (`/revoke`) и обновите секрет.

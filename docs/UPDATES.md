# Обновления CarScan через GitHub

Приложение при запуске (через 5 секунд) и по кнопке **«… → Обновления → Проверить»** запрашивает последний
релиз репозитория [SolidniyGoose/CarScan](https://github.com/SolidniyGoose/CarScan/releases).
Если его версия новее установленной, на кнопке «…» появляется жёлтая точка, а в настройках — кнопка **«Обновить»**.
APK скачивается в кэш приложения, после чего открывается системный установщик Android.

Релизы собирает GitHub Actions (`.github/workflows/release.yml`) при пуше тега `v*`.

## Один раз: ключ подписи

Android ставит обновление поверх, только если оно подписано **тем же ключом**. Поэтому нужен свой постоянный ключ,
общий для GitHub Actions и Android Studio.

1. В PowerShell в папке проекта:
   ```powershell
   .\tools\create_release_key.ps1
   ```
   Появятся `carscan-release.jks`, `keystore.properties` и `carscan-release.jks.base64.txt`. Все три в `.gitignore`.
2. GitHub → репозиторий → **Settings → Secrets and variables → Actions → New repository secret** — добавьте четыре
   секрета, которые напечатал скрипт: `CARSCAN_KEYSTORE_BASE64`, `CARSCAN_KEYSTORE_PASSWORD`, `CARSCAN_KEY_ALIAS`,
   `CARSCAN_KEY_PASSWORD`.
3. Сохраните копию `carscan-release.jks` и `keystore.properties` вне репозитория (облако, флешка).
   **Потеряете ключ — обновления перестанут вставать поверх, придётся удалять приложение.**
4. После этого Android Studio тоже подписывает сборки этим ключом. Версию, установленную раньше с отладочным
   ключом, **один раз удалите** с планшета и поставьте заново (настройки приложения при этом сбросятся).

## Каждый релиз

1. Увеличьте `appVersion` в `gradle.properties` (например, `1.0.1`) и закоммитьте изменения.
2. Создайте и отправьте тег с той же версией:
   ```bash
   git tag v1.0.1
   git push origin main v1.0.1
   ```
3. Через 5–10 минут на вкладке **Actions** будет готова сборка, а в **Releases** появится `CarScan-v1.0.1.apk`.
4. На планшете: «…» → «Обновления» → «Проверить» → «Обновить». При первом обновлении Android попросит разрешить
   CarScan установку приложений — разрешите и нажмите «Обновить» ещё раз.

## Если не обновляется

| Сообщение | Что делать |
|---|---|
| «На GitHub пока нет релизов» | Тег не отправлен или сборка в Actions упала (вкладка Actions) |
| «Релиз подписан другим ключом» | Установлена версия с отладочным ключом — удалите приложение и поставьте APK из релиза вручную |
| «Установлена последняя версия», хотя релиз новее | Версия в теге не больше установленной (`appVersion` в `gradle.properties`) |
| Ошибка Actions «Не задан секрет …» | Не добавлены секреты из шага «Ключ подписи» |

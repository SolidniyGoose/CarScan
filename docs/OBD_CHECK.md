# Проверка считывания OBD2 на реальном автомобиле

## Что уже проверено без машины

| Что | Где | Как |
|---|---|---|
| Формулы пересчёта байтов в значения | `ObdDecodeTest` (12 тестов) | Эталонные примеры SAE J1979: `41 0C 1A F8` → 1726 об/мин, маска `BE 1F A8 13` → PID 01, 03–07, 0C–11, 13, 15, 1C, 1F, 20 и т. д. |
| Разбор ответов ELM327 | `ElmParsingTest` (8 тестов) | Ответы с пробелами и без, эхо, `SEARCHING...`, несколько ЭБУ, многокадровые ответы CAN, `NO DATA`, `UNABLE TO CONNECT`, `?` |
| Полный сеанс опроса | `ObdTelemetrySourceTest` (6 тестов) | Эмулятор ELM327 отвечает как адаптер на CAN-машине: инициализация, поиск PID, опрос, расход по MAF, режим 06, команда производителя, ошибка «зажигание выключено» |

**Не проверено:** настоящий Bluetooth-адаптер, настоящий ЭБУ Mercedes и скорость обмена. Это и есть цель проверки ниже.

## Что читается и откуда

| Показатель | Запрос | Формула | Примечание |
|---|---|---|---|
| Температура ОЖ | `01 05` | A − 40 | |
| Обороты | `01 0C` | (256·A + B) / 4 | |
| Скорость | `01 0D` | A | км/ч |
| Нагрузка двигателя | `01 04` | A · 100 / 255 | |
| Уровень топлива | `01 2F` | A · 100 / 255 | Литры = % × объём бака из профиля автомобиля. Нет 2F — команда производителя, см. шаг 5 |
| Расход, л/ч | `01 5E` | (256·A + B) / 20 | Если ЭБУ не даёт 5E — расчёт по MAF |
| Расход по MAF | `01 10` | MAF / 14.7 / 745 × 3600 × (1 + коррекции/100) | Только бензин. Дизель без 5E — расход не считается |
| Расход без MAF | `01 0B`, `01 0C`, `01 0F` | воздух = MAP·V·об/мин·КН / (287·T·120) | Нужны объём двигателя и коэффициент наполнения из профиля автомобиля |
| Средний расход | — | ∫расход dt / ∫скорость dt × 100 | Бортовой компьютер приложения, кнопка «Сбросить поездку» |
| Напряжение сети | `AT RV` | как есть | Меряет сам адаптер на 16-м контакте; запасной вариант `01 42` |
| Улица | интернет | — | Open-Meteo; запасной вариант — датчик `01 46` (A − 40) |
| Темп. впуска, давление | `01 0F`, `01 0B` | A − 40, A | |
| Топливные коррекции | `01 06`, `01 07` | (A − 128) · 100 / 128 | |
| Check Engine, число ошибок, готовность | `01 01` | биты A–D | |
| Пропуски зажигания | `06 A2…AD` | TID 0C (текущий цикл) или 0B | Только CAN |
| **Температура АКПП (ATF)** | — | — | **Нет в стандарте OBD-II**, только команда производителя, см. шаг 5 |
| **Температура салона** | — | — | **Нет в стандарте OBD-II**, только команда производителя, см. шаг 5 |
| Передача | — | — | Нет в стандарте; на экране «—» |

## Что понадобится

- Адаптер **ELM327 Bluetooth Classic** (SPP): «OBDII», «V-LINK», Vgate iCar 2 Bluetooth, Konnwei KW902 и т. п. Адаптеры только с BLE (Vgate iCar Pro BLE, OBDLink CX, Bluetooth 4.0) и Wi-Fi-адаптеры пока **не поддерживаются**.
- Телефон или магнитола с Android 8+ и установленным `app-debug.apk`.
- Для сравнения — Car Scanner на том же устройстве. По желанию — мультиметр.

## Шаг 1. Подготовка

1. Вставьте адаптер в разъём OBD. У Mercedes GLS он обычно под панелью слева от рулевой колонки.
2. Включите зажигание или заведите двигатель.
3. Android → Настройки → Bluetooth → найдите адаптер и выполните сопряжение (PIN обычно `1234` или `0000`).
4. **Полностью закройте Car Scanner** (смахните из недавних). Адаптер держит только одно подключение.

## Шаг 2. Подключение в CarScan

1. Нажмите **«…»** внизу слева, откроются **Настройки**. В разделе **«Автомобиль»** нажмите **«Выбрать авто»** и укажите марку, модель и двигатель. Если бак или объём двигателя у вашей машины другой, поправьте кнопками «−/+».
2. **Источник данных → Bluetooth ELM327.** На Android 12+ разрешите доступ к «Устройствам поблизости».
3. **Адаптер ELM327:** выберите свой адаптер. Если список пуст, нажмите **«Адаптеры»**.
4. Смотрите на строку слева вверху:
   - «ПОДКЛЮЧЕНИЕ OBD2…» (жёлтая точка) — идёт подключение и поиск протокола, до ~15 секунд. Протокол и способ Bluetooth-подключения запоминаются по адресу адаптера, поэтому со второго раза поиска нет (`AT SP A6` вместо `AT SP 0`). Проверка датчиков идёт уже после первых показаний;
   - «OBD2 · ISO 15765-4 CAN» (зелёная точка) — подключено. На GLS ожидается CAN 11 бит, 500 кбит/с;
   - «НЕТ СВЯЗИ С OBD2» (красная точка) — причина видна в «Настройки → Источник данных → Состояние».

После ошибки приложение само переподключается каждые 5 секунд. Кнопка питания внизу останавливает и снова запускает опрос.

## Шаг 3. Журнал OBD — проверка «сырых» данных

**Настройки → Журнал OBD.**

1. **Адаптер (AT I):** у оригинала `ELM327 v1.4b`/`v2.x`. Клоны часто пишут `v1.5` или `v2.1` — это нормально.
2. **Протокол:** для GLS — `ISO 15765-4 CAN (11 бит, 500 кбит/с)`.
3. **PID режима 01:** что поддерживает ЭБУ. Если в списке нет `2F`, уровня топлива не будет (на экране «—»). Нет `46` — нет датчика улицы в OBD (уличная температура всё равно придёт из интернета).
4. **Обмен (новые сверху):** запрос → ответ → расшифровка. Любую строку можно пересчитать вручную:

   ```
   010C → 410C0A9C = 679 об/мин      0x0A = 10, 0x9C = 156 → (10·256 + 156) / 4 = 679 ✔
   0105 → 41057B   = 83 °C           0x7B = 123 → 123 − 40 = 83 ✔
   012F → 412F9E   = 62.0 %          0x9E = 158 → 158 · 100 / 255 = 62.0 ✔
   ```

   `NO DATA` у отдельного PID значит, что ЭБУ его не отдаёт. После трёх таких ответов приложение перестаёт его спрашивать.

   Цифра в конце запроса (`010C2`, `01041`) — сколько блоков должны ответить: столько заявили этот PID в масках `0100/0120/0140`. Адаптер отдаёт ответ сразу, как ответили все, и не ждёт тишины на шине. Car Scanner делает так же: на Outlander XL это 25–40 мс на запрос вместо 60–120. Если адаптер ответил `?`, приложение пишет об этом в журнал и дальше опрашивает без цифры.

## Шаг 4. Сверка показателей

Сравнивайте в одинаковых условиях. Car Scanner и CarScan запускайте **по очереди**: сначала одно приложение (запишите значения), закрыть, потом другое.

| Параметр | Как проверить | Ожидаемо | Допуск |
|---|---|---|---|
| Обороты | Прогретый холостой ход, затем держать ~2000 по тахометру | ХХ ≈ 600–700 | ±50 об/мин (стрелка на приборке инерционна) |
| Скорость | 60 км/ч на круизе, сравнить со скоростью GPS в навигаторе | Спидометр приборки завышает на 2–5 %, OBD ближе к GPS | ±2 км/ч к GPS |
| Темп. ОЖ | Холодный пуск, затем прогрев | После ночи ≈ температура воздуха; прогретый 85–105 °C | ±1 °C к Car Scanner |
| Напряжение | Двигатель заглушен: мультиметр на клеммах АКБ. Затем заведён | 12.4–12.8 В заглушен, 13.8–14.8 В заведён | ±0.2 В (AT RV меряет на разъёме OBD) |
| Топливо | Сразу после полной заправки | ≈100 % и ≈90 л | ±3 % (поплавок раскачивается в поворотах) |
| Средний расход | Сбросьте поездку в CarScan («Главная → Сбросить поездку») и бортовой компьютер авто, проедьте 20+ км | Близко к бортовому компьютеру | ±10 % по MAF, ±5 % если есть PID 5E |
| Улица | Сравнить с дисплеем машины | Разница 1–3 °C нормальна | Датчик в бампере греется в пробке |
| Check Engine, тесты | Car Scanner → «Тесты на выбросы» | Совпадают | — |
| Пропуски зажигания | Car Scanner → режим 06 / «Мониторинг ЭБУ» | Совпадают | — |

Если значение расходится больше допуска, сделайте скриншот «Журнала OBD» в этот момент. По сырым байтам сразу видно, в чём дело: в формуле или в ответе ЭБУ.

## Шаг 5. Уровень топлива, температура АКПП и салона (команды производителя)

Температур АКПП и салона в стандарте OBD-II нет, а уровень топлива (PID 2F) отдают не все машины. Car Scanner и Torque берут их из блоков машины по командам производителя. В CarScan команды задаются по марке и модели в `data/ManufacturerPids.kt`.

### Mitsubishi Outlander (XL и III)

| Показатель | Блок | Запрос → ответ | Команда | Байт и формула |
|---|---|---|---|---|
| Уровень топлива | приборы | `6A0` → `514` | `21 A3` | C − 16 = %, 16 — пусто, 116 — полный бак |
| Темп. в салоне | климат-контроль | `688` → `511` | `21 10` | A / 4 − 16 °C |
| Темп. вариатора (JF011E, только XL 2.0/2.4) | вариатор | `7E1` → `7E9` | `21 03` | N (14-й байт): полином 2.344e-9·N⁵ − 1.387e-6·N⁴ + 3.193e-4·N³ − 0.03501·N² + 2.302·N − 36.6 |

Байты считаются после эха запроса (`61 A3`, `61 10`, `61 03`): A — первый, C — третий, N — четырнадцатый. Команды взяты из профилей Torque владельцев (форум out-club.ru, файлы `OUT3.csv` и «Mitsubishi Outlander 2008–2015»). Топливо и салон там описаны для Outlander III. **На XL их с приборкой никто не сверял:** проверьте при первом подключении.

- **Топливо:** сразу после полной заправки должно быть ≈100 %, затем сравнивайте со стрелкой.
- **Салон:** сравните с термометром в салоне. У машин без климат-контроля блок 688 не ответит, и в строке будет «—».
- **Вариатор:** после ночи на стоянке температура должна быть близка к уличной, после 20 минут езды — 60–90 °C.

Приборы и климат отвечают не с «адреса запроса + 8». Поэтому перед запросом приложение задаёт адаптеру фильтр приёма и flow control: `AT SH 6A0`, `AT FC SH 6A0`, `AT FC SD 30 08 0A`, `AT FC SM 1`, `AT CRA 514`. После запроса оно возвращает автоматический режим: `AT FC SM 0`, `AT AR`, `AT SH 7DF`.

Если блок трижды подряд не дал значения, приложение перестаёт его спрашивать до следующей проверки датчиков. Сырой ответ виден в «Проверке датчиков» (строки `6A0 21A3`, `688 2110`, `7E1 2103`) и в отчёте. Если значение неверное, «Глубокое сканирование» (службу 21 у двигателя, коробки, приборов и климата) нужно сделать дважды: при разном уровне топлива или на холодной и прогретой машине. Нужный байт тот, который изменился.

### Как добавить команду для другой машины

```kotlin
// data/ManufacturerPids.kt, forVehicle(...)
atfTemp = ExtendedPid(name = "Темп. АКПП", header = "7E1", command = "22XXXX", unit = " °C", range = -40.0..150.0) { it.getOrNull(0)?.let { a -> a - 40.0 } },
```

- `header` — адрес блока (у АКПП на CAN обычно `7E1`), `receive` — адрес ответа, если он не `header + 8`;
- `command` — запрос (`22` + номер параметра или `21` + идентификатор);
- `decode` — формула по байтам ответа после эха запроса (`62 XX XX` или `61 XX`); значения вне `range` отбрасываются.

Приложение само переключит заголовок и вернёт его обратно. Расшифровка появится в журнале.

> ⚠️ Отправляйте только **чтение** (сервисы `01`, `09`, `21`, `22`). Сервисы `04` (стирание ошибок), `2E`, `31`, `3B` меняют настройки блоков.

## Если не работает

| Симптом | Причина и что делать |
|---|---|
| Адаптера нет в списке | Не сопряжён в Android, выключен Bluetooth или нет разрешения «Устройства поблизости» (Настройки Android → Приложения → CarScan → Разрешения) |
| «Не удалось подключиться к …» | Адаптер занят другим приложением, без питания (зажигание) или это BLE-адаптер |
| «ЭБУ не отвечает: включите зажигание» | Адаптер ответил `UNABLE TO CONNECT`. Включите зажигание. Если не помогло, дешёвые клоны «v2.1» бывают несовместимы с CAN — попробуйте другой адаптер |
| «Адаптер не ответил на … за 2 с» | Адаптер завис: выньте его из разъёма на 10 секунд |
| Отдельное значение «—» | ЭБУ не поддерживает этот PID (нет в списке «PID режима 01» или в журнале `NO DATA`) |
| Значения обновляются медленно | Клоны ELM327 успевают 10–25 запросов в секунду с числом ответов в запросе. Обороты и скорость опрашиваются каждый цикл, температуры реже, остальные PID из «Все датчики → Все параметры ЭБУ» — по одному за цикл |
| Средний расход «—» или нереальный | Дизель без PID 5E. Неверный автомобиль, объём двигателя или бак в «… → Автомобиль». Способ расчёта виден в «Датчики → Расчёт расхода» |
| Расход «MAP × …» завышен или занижен | Подстройте «Коэф. наполнения» (85 % по умолчанию) так, чтобы средний расход совпал с бортовым компьютером |

- `app/src/main/java/com/carscan/data/obd/ObdDecode.kt` — формулы;
